TASK 5 — BUILD THE FOOD SEARCH FASTAPI ENDPOINT
───────────────────────────────────────────────────────────
IMPORTANT: register /foods/search and /foods/categories 
routes BEFORE /foods/{food_id} in the router file.
Failure to do this will cause FastAPI to treat 
"search" and "categories" as food_id values.
Write the food search router at:
app/routers/foods.py

Endpoints to implement:

GET /api/v1/foods/search
  Query params: q (search term), category (optional filter),
                limit (default 20, max 50), offset (default 0)
  Auth: required (JWT)
  Response: paginated list of FoodResponse
  Logic: search static.foods by name ILIKE %q%
         optionally filter by category
         return paginated results

GET /api/v1/foods/{food_id}
  Auth: required (JWT)
  Response: single FoodResponse with full nutrient detail
  Edge case: 404 if food not found

GET /api/v1/foods/categories
  Auth: required (JWT)
  Response: list of distinct categories in static.foods
  Use: populates category filter dropdown in React

Write the food service at:
app/services/food_service.py
  - search_foods(db, query, category, limit, offset)
  - get_food_by_id(db, food_id)
  - get_categories(db)

Register the router in app/main.py
