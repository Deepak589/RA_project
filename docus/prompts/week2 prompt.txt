Design rules to follow:
- Use UUID primary keys on all tables
- Use TIMESTAMPTZ not TIMESTAMP for all datetime fields
- Store JSON columns as JSONB not JSON in PostgreSQL
- flare_level should be an ENUM type: none, mild, moderate, severe
- feedback_status in recommendation_logs should be ENUM: 
  pending, accepted, skipped, replaced
- lifestyle_logs should UNIQUE on (user_id, log_date) to enforce 
  one record per day (upsert pattern)
- authentication_sessions refresh_token_hash should be indexed
- food_logs.logged_at and symptom_logs.logged_at should be indexed 
  for date-range queries
